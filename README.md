# culmProject_2025
**Title:** Williams' Site

**Description:** <br>
A dynamic web application designed for Dr. GW Williams SS to streamline the communication between staff and students/parents. Built using Python Flask and SQLite, it gives a role-based access control that allows teachers/admins to manage daily content while providing students/parents with a clear and tidy view-only platform. 

**Features:** <br>
The project features a role-based system that allows teachers/admins to log in and edit the information shared to students/parents. The **Home** page features key information about the school, like contacts and bell times. **The Announcements** page shows the daily announcements updated by staff. The **Calendar** page displays the months of the school year (Sept-June), and any events added by staff (along with colour-coded categories). The **Clubs** page allows staff to add and manage clubs and display them to the viewers. The **Q&A** page allows students/parents to interact/ask questions(managed before appearing publicly) and view answers from staff. The **Resources** page is static and contains links to various resources (like Kids Help Phone, Teach Assist, etc) for easy access. The **Account Management** page allows only admins to view all the accounts and have the access to change roles, reset password, disable an account, and remove. The **History** page is view-only and displays all the history logs saved when edits are made across the different pages (there is a clear history button).
